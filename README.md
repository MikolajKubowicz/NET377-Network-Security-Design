
# Network Security Design – Cisco Packet Tracer

## Overview
Designed and simulated a multi-segment enterprise network for a fictional organization, Joe's Snacks, using Cisco Packet Tracer.

## Technologies
- Cisco Packet Tracer
- Cisco IOS
- IPv4 subnetting
- Static routing
- NAT/PAT
- Firewall access control lists (ACLs)
- HTTP and ICMP connectivity testing

## Network Architecture
The topology includes Red and Green network paths, a DMZ, an intranet, an internal client network, and a simulated public Internet network.

## Implementation
- Created and assigned IP subnets across multiple network segments.
- Configured routing between internal networks and the simulated Internet.
- Implemented static NAT/PAT for public access to internal web services.
- Designed firewall ACL specifications.
- Tested connectivity using ping, traceroute, and web browsers.

## Validation
Verified Internet access to the sales server, access to the remote desktop gateway, connectivity between internal clients and database/AD/HR servers, and access from the web security gateway to a simulated public web server.
